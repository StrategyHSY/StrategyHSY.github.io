这是博客的第一篇示例文章。你可以直接编辑它，换成自己的学习内容。

## 为什么记录学习

读懂一个概念和能够解释清楚它，往往是两件事。把知识写下来，可以帮助自己发现理解中的空白。

一篇笔记不必很长，先写清楚一个具体问题就足够了。

## 一篇笔记的结构

1. **问题**：我想弄清楚什么？
2. **理解**：这个概念的核心是什么？
3. **例子**：能否用一个例子说明？
4. **复盘**：哪些地方还不确定，下一步怎么验证？

## 代码与公式

如果写编程笔记，可以直接加入代码块：

```python
def review(notes):
    for note in notes:
        print(f"今天复习：{note}")

review(["一个新概念", "一个实践问题"])
```

数学内容也可以使用 LaTeX 语法，例如平均值：

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i
$$
